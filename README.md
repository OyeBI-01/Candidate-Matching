### Candidate Matching System

Overview

The Candidate Matching System is a machine learning-based application designed to streamline the recruitment process. It intelligently matches job candidates to roles based on their skills, experience, and preferences, leveraging advanced algorithms and natural language processing techniques to ensure accurate and efficient recommendations.

# Features

Job-Candidate Matching: Matches candidates to job openings based on key parameters such as skills, experience, and job description.

Resume Parsing: Extracts relevant information from candidate resumes using NLP techniques.

Job Description Analysis: Breaks down job descriptions into key skill requirements and role responsibilities.

Scoring System: Provides match scores to rank candidates for specific job openings.

Customizable Filters: Allows recruiters to fine-tune the matching criteria.

Interactive Frontend: Built using Streamlit for easy access to results and insights.
